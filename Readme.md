# NEXORA

### تمام دنیا در یک جا

NEXORA یک شبکه اجتماعی و پیام‌رسان بین‌المللی است.

## امکانات اصلی
- ثبت‌نام و ساخت حساب کاربری
- پیام خصوصی و گروهی
- انتشار پست و عکس
- ساخت گروه و کانال
- حفظ حریم خصوصی کاربران

## برنامه آینده
ساخت یک شبکه اجتماعی امن، سریع و قابل دسترس برای همه مردم جهان.

نسخه اولیه در حال برنامه‌ریزی است.
